# ExCal - Smart Expense Tracker

ExCal is a web-based expense tracking application developed using Flask and SQLite.

## Features

- User Registration and Login
- Add Income
- Add Expenses
- Dashboard with financial summary
- Expense category tracking
- Reports and charts
- SQLite database
- Responsive web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Bootstrap
